Atividade Prática: Sistema de Controle de Estoque de Produtos

1. Contexto do Desafio

Nesta atividade prática, você irá replicar e adaptar a arquitetura de uma aplicação web completa, desenvolvendo um sistema de Cadastro e Controle de Estoque de Produtos. A aplicação integrará:

  • Frontend: HTML5, CSS3 e JavaScript consumindo a API com Axios via CDN.
  • Backend: Node.js com Express, modularizado e com credenciais protegidas via dotenv.
  • Banco de Dados: MySQL (criado via MySQL Workbench) com suporte a Soft Delete (exclusão lógica).

2. Objetivos de Aprendizagem

  • Construir a modelagem de dados no MySQL com campos numéricos inteiros, decimais e booleanos.
  • Centralizar a conexão do banco de dados em um módulo isolado e utilizar variáveis de ambiente.
  • Implementar rotas HTTP RESTful (GET, POST, PUT e PATCH) com tratamento de exceções e códigos de status HTTP apropriados.
  • Consumir endpoints no frontend com Axios utilizando a sintaxe async/await e manipulação dinâmica do DOM.

3. Especificação do Banco de Dados (MySQL Workbench)

No MySQL Workbench, crie a base de dados app_estoque e a tabela produtos conforme as definições abaixo:

  • id: INT, AUTO_INCREMENT, Chave Primária
  • nome: VARCHAR(100), Obrigatório (NOT NULL)
  • descricao: TEXT, Opcional (NULL)
  • quantidade: INT, Obrigatório, Padrão 0
  • preco: DECIMAL(10,2), Obrigatório
  • ativo: BOOLEAN, Padrão TRUE (1)
  • criado_em: TIMESTAMP, Padrão CURRENT_TIMESTAMP

4. Especificação do Backend (Node.js + Express)

Organize a pasta backend/ com a seguinte estrutura:

  • .env: Contendo PORT=3000, DB_HOST=localhost, DB_USER=root, DB_PASSWORD=suasenha e DB_NAME=app_estoque.
  • db.js: Arquivo isolado que cria e exporta o pool de conexões (mysql2/promise).
  • server.js: Servidor Express com CORS, JSON middleware e as rotasda API.

Rotas Obrigatórias da API:

  1. GET /api/produtos: Retorna todos os produtos ativos (WHERE ativo = TRUE) ordenados pelo ID decrescente.
  2. POST /api/produtos: Cadastra um novo produto (valida campos obrigatórios: nome, quantidade e preco).
  3. PUT /api/produtos/:id: Atualiza os dados de um produto existente.
  4. PATCH /api/produtos/:id/desativar: Realiza a exclusão lógica (Soft Delete), alterando o campo ativo para FALSE sem remover a linha do banco.

5. Especificação do Frontend (HTML, CSS e app.js)

Organize a pasta frontend/ com:

  • index.html: Interface contendo o formulário dinâmico, tabela de listagem e a importação do Axios via CDN.
  • style.css: Estilização visual dos formulários, botões e tabela de registros.
  • app.js: Arquivo de regras contendo a instância do Axios (baseURL: 'http://localhost:3000/api') e as funções assíncronas de comunicação com a API.

6. Roteiro de Execução Passo a Passo

  1. Banco de Dados: Abra o MySQL Workbench e execute o script SQL para criar o schema e a tabela.
  2. Ambiente Backend: Inicie o projeto com npm init -, instale os pacotes express, cors, mysql2 e dotenv.
  3. Implementação Backend: Configure as variáveis no .env, estabeleça a conexão no db.js e codifique as quatro rotas no server.js.
  4. Implementação Frontend: Construa a interface HTML e programe no app.js as chamadas de listar, cadastrar, editar e desativar produtos.
  5. Validação e Testes: Cadastre produtos de exemplo, atualize quantidade/preço, desative um produto e verifique a persistência dos dados no MySQL Workbench.
